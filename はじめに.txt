brain-ai v1 preview
==================================================

brain-ai は、電子辞書のような非力な端末の上で、オフラインのまま動作する日本語の小型 AI です。
v1 preview は最初の公開版で、日常会話・相談・計算・プログラミングに関する簡単な質問に対応しています。

本版はプレビュー版です。モデルが非常に小さいため（約 1,470 万パラメータ）、
回答に誤りが含まれることがあります。正確さが求められる用途には使用しないでください。

--------------------------------------------------
収録内容
--------------------------------------------------
  Brain\      シャープ 電子辞書 Brain（Windows CE 6.0）用

  いずれも、実行ファイルと同じフォルダにある model.bin、tok.bin、igc.bin を使用します。
  フォルダの構成は変更せずにお使いください。


--------------------------------------------------
Brain での使い方
--------------------------------------------------
  1. Brain フォルダ内の「アプリ」フォルダを、SD カードの最上位にコピーします。
     コピー後、SD カード内が次の構成になっていることを確認してください。
       \アプリ\brainai\AppMain.exe
       \アプリ\brainai\AppMain.cfg、index.din、model.bin、tok.bin、igc.bin
  2. Brain のメニューから、追加したアプリ（brainai）を起動します。

  注意
  ・機種によっては、追加アプリの起動に制限があります。その場合は、AppMain.exe を
    AppMain_.exe に名前を変更し、起動用のツール（exeopener など）を併用する必要があります。
  ・Brain 実機での動作は未検証です。不具合があった場合は、表示された内容とあわせてお知らせください。


--------------------------------------------------
入力について
--------------------------------------------------
  ・ローマ字で入力すると、送信時にひらがなへ変換されます（例: konnichiha → こんにちは）。
  ・［ ］で囲んだ部分は変換されません。数式や英単語の入力に使用してください（例: [123*45]wa? ）。
  ・［かな］のチェックを外すと、入力した文字列をそのまま送信します。


--------------------------------------------------
主な機能
--------------------------------------------------
  ・日常会話、相談への応答
  ・計算: 四則演算・百分率・べき乗は内蔵の計算ユニットで、関数計算は内蔵の関数電卓で正確に処理します。
  ・Python / C / C++ / Java / Go に関する簡単な質問への回答


--------------------------------------------------
既知の制限
--------------------------------------------------
  ・ひらがなのみの質問では、意図を正しく理解できないことがあります。
  ・曜日の計算、会話の前半に出た内容の参照、長い文章の生成は不得意です。
  ・関数電卓を使う質問で、意図と異なる式を計算することがあります。
